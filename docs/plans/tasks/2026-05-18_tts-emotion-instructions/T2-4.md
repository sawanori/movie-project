### Step 3: tts_instructions を追加

`use_lip_sync: dialogueData.useLipSync,` の直後に追加:

```typescript
const result = await dialogueApi.create({
  video_url: videoUrl,
  text: dialogueData.text,
  voice_id: dialogueData.voiceId,
  speed: dialogueData.speed,
  use_lip_sync: dialogueData.useLipSync,
  tts_instructions: dialogueData.ttsInstructions || undefined,
  // 空文字 ('') は undefined に正規化してバックエンドに送らない (AC10a)
  // JSON.stringify は undefined キーを省略するため、バックエンドは tts_instructions を受け取らない

```

`dialogueData.ttsInstructions || undefined` のパターン:
- `undefined` → `undefined` (省略)
- `''` (空文字) → `undefined` (省略、AC10a 準拠)
- `'custom text'` → `'custom text'` (送信)

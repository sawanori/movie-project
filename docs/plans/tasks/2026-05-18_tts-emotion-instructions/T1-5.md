# T1-5: Supabase migration — dialogue_generations + tts_generations にカラム追加

## 依存タスク

なし (T1-1 / T1-2 と並列実行可能)

## 目的

`dialogue_generations.tts_instructions` (TEXT, nullable) と `tts_generations.instructions` (TEXT, nullable) を追加する migration SQL を作成し、Supabase に適用する。T1-3 / T1-4 の BE 実装が実環境で動作するために必須。

## 対象ファイル

- `/Users/noritakasawada/AI_P/practice/movie-project/docs/migrations/20260518_add_tts_instructions.sql` (新規作成)

## 実装手順

### Step 1: migration SQL を作成

```sql
-- ========================================================
-- 2026-05-18: TTS instructions カラム追加
-- dialogue_generations: ユーザーが UI から指定した instructions を保存
-- tts_generations: dialogue_processor が伝播した instructions を保存
-- ========================================================

-- dialogue_generations に tts_instructions カラムを追加
ALTER TABLE dialogue_generations
  ADD COLUMN IF NOT EXISTS tts_instructions TEXT;

-- tts_generations に instructions カラムを追加
ALTER TABLE tts_generations
  ADD COLUMN IF NOT EXISTS instructions TEXT;

-- 後方互換: 両カラムとも NULL 許容、DEFAULT なし
-- 既存レコードは NULL のまま。新規 INSERT 時に省略すれば NULL。
-- RLS ポリシーは既存テーブルポリシーをそのまま継承するため変更不要。

-- コメント追記
COMMENT ON COLUMN dialogue_generations.tts_instructions IS
  '感情/トーン指定 (gpt-4o-mini-tts のみ適用). UI から指定された instructions 文字列。NULL = デフォルト適用。';
COMMENT ON COLUMN tts_generations.instructions IS
  'dialogue_processor から伝播された TTS instructions。NULL = デフォルト適用。';
```

### Step 2: Supabase MCP で migration を適用

Supabase MCP ツール (`mcp__supabase__apply_migration`) を使って上記 SQL を適用する。

実行前に対象プロジェクトが正しいことを確認すること。

### Step 3: カラムの存在を確認

Supabase ダッシュボード (Table Editor) または MCP `list_tables` で `dialogue_generations` と `tts_generations` の両テーブルに新カラムが追加されていることを確認する。

```sql
-- 確認クエリ (Supabase SQL Editor または MCP経由)
SELECT column_name, data_type, is_nullable
FROM information_schema.columns
WHERE table_name IN ('dialogue_generations', 'tts_generations')
  AND column_name IN ('tts_instructions', 'instructions')
ORDER BY table_name, column_name;
```

期待結果: 2 行が返り、`is_nullable = 'YES'` であること。

## 検証

migration 適用後:
1. Supabase の `dialogue_generations` テーブルに `tts_instructions TEXT` カラムが存在すること
2. Supabase の `tts_generations` テーブルに `instructions TEXT` カラムが存在すること
3. 既存レコードに影響がないこと (`NOT NULL` 制約なし、DEFAULT なし)

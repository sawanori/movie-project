### Step 2: tts_instructions フィールドを追加

`use_lip_sync?: boolean;` の直後に追加:

```typescript
type DialogueCreatePayload = {
  video_url: string;
  text: string;
  voice_id: string;
  speed?: number;

```

`dialogueApi.create` の本体は変更不要。`...payload` スプレッドで `tts_instructions` が自動的に含まれる (L2042):

```typescript
create: (payload: DialogueCreatePayload): Promise<DialogueCreateResult> =>
  fetchWithAuth('/api/v1/dialogue', {
    method: 'POST',
    body: JSON.stringify({ ...payload, language: 'ja' }),
    timeout: 900_000,
  }),
```

`tts_instructions` が `undefined` の場合、`JSON.stringify` はそのキーを省略するため AC10a の要件を自然に満たす。

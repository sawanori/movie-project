# T1-4: dialogue_processor + tts/service + tts_processor に instructions を配線

## 依存タスク

- T1-3 完了後 (`dialogue_generations.tts_instructions` が DB に保存されること)
- T1-5 完了後 (migration 適用済みで `tts_instructions` / `instructions` カラムが存在すること)

## 目的

`dialogue_processor.py` が DB レコードから `tts_instructions` を読み取り `create_tts_generation` に渡し、`tts/service.py` がそれを `tts_generations.instructions` に INSERT し、`tts_processor.py` が `record.get("instructions")` を取得して `provider.generate_speech(instructions=...)` に渡すよう、残り 3 ファイルの配線を完成させる。

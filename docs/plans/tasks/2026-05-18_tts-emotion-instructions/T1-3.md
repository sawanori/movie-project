`create_dialogue_generation` のシグネチャに `tts_instructions: Optional[str] = None` を追加し、`record_data` dict に含める。

変更前 (L16-25):

変更後:
```python
async def create_dialogue_generation(
    user_id: str,
    video_url: str,
    text: str,
    voice_id: str,
    language: str = "ja",
    speed: float = 1.0,
    use_lip_sync: bool = False,

```

`record_data` dict に追記 (L42-53 の `record_data` ブロック内):
```python
record_data = {
    "user_id": user_id,

    "text": text,

    "speed": speed,
    "use_lip_sync": use_lip_sync,
```

変更後:

```python
record = await create_dialogue_generation(
```

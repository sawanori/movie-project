### Phase 4: Acceptance Criteria 手動検証

以下の AC を順に手動で確認する。開発サーバー (`uvicorn app.main:app` + `npm run dev`) を起動した状態で実施。

#### AC-A1: typo 修正 (Reserve → Preserve)
- PromptNode に「赤いセーターを着た女性が手を振る」を入力
- 翻訳完了後に表示された英語プロンプトに "Reserve exact appearance" / "Reserve the subject" が含まれていないこと
- "Preserve" が少なくとも 1 箇所含まれること

#### AC-B1: 主体情報保持 (object サブジェクト)
- subject_type = object、入力「ベージュのニットセーター。手足なし、ハンガー吊り」
- 翻訳結果に "beige" 相当の語が含まれること
- "knit" 相当の語が含まれること
- "hanger" / "hung" / "suspended" 相当の語が含まれること
- "Same face" が含まれないこと

#### AC-B2: テンプレ軽量化 (文字数ソフト目標)
- 上記 AC-B1 と同じ入力で翻訳
- `english_prompt.length <= 1200` であること (推奨、ハード上限なし)
- サーバーログに "exceeded soft target" が出ていた場合は warning レベルのみであること

#### AC-B3: subject_type='object' で人物前提フレーズ不在
- 翻訳結果に "Same face, same hair, same clothing" 系フレーズが含まれないこと

#### AC-B4: Act-Two 引数の Phase 1 処理
- 開発者ツールまたは curl で `use_act_two: true` を含むリクエストを送信
- HTTP 200 で翻訳結果が返ること
- サーバーログに "Act-Two mode is not supported" warning が出ること

#### AC-C1: セリフ抽出 (単一)
- 入力「キャラクターが『ちょっと まって…』と言う」
- `extracted_dialogue === "ちょっと まって…"` であること
- 英語プロンプト本文に「ちょっとまって」が含まれないこと
- 英語プロンプトに "lip" / "speak" / "mouth" のいずれかが含まれること

#### AC-C2: セリフ抽出 (複数)
- 入力「「あ…」と言ってから「やめて…」と続ける」
- `extracted_dialogue` に "あ…" と "やめて…" の両方が含まれること

#### AC-C3: セリフなし入力で extracted_dialogue が null
- 入力「女性が振り向く」
- 確認カードが表示されないこと

#### AC-C4: 確認カード UI 表示
- セリフ含む入力後に翻訳完了
- 「セリフを検出しました」テキストが表示されること
- 3 ボタンが表示されること

#### AC-C5: 新規 DialogueNode 自動配置
- 「新規 DialogueNode を作成」をクリック
- グラフに DialogueNode が 1 個追加されること
- 位置が PromptNode の右下であること

#### AC-C6: 既存 DialogueNode への転記
- 既存 DialogueNode がある状態で「既存ノードに転記」をクリック
- 既存 DialogueNode の text が updated_dialogue で上書きされること

#### AC-C7: 「無視」後の dismiss 抑制
- 「無視」クリック後、同じプロンプトで再翻訳してもカードが出ないこと

#### AC-C8: ネストカッコ挙動 (自動テスト済み、実機確認)
- 入力「「彼は『やめて』と叫んだ」」で extracted_dialogue に両方のセリフが含まれること

#### AC-C9: subject_type='object' で 人物フレーズ混入しない (自動テスト済み)

#### AC-D1: 既存ワークフロー保護
- storyboard 画面から従来の翻訳 (`/storyboard/translate-scene`) を実行
- 正常にレスポンスが返ること (`runway_prompt` フィールドが存在)

#### AC-D2: 既存 englishPrompt の保持
- 保存済みワークフローを開いて動画生成
- 旧テンプレで生成した `englishPrompt` が動画生成 API に渡されること

#### AC-E1: Kling 2500 文字制限安全確認
- Kling プロバイダーで長い入力 (日本語 400 文字程度) を翻訳
- 英語プロンプトが 2500 文字以下であること (truncate されない)
